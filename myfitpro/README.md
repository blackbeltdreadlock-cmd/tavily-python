# MyFit Pro

Frontend inicial do aplicativo para academias, personal trainers e alunos.

## Rodar localmente

```bash
cd myfitpro/frontend
npm install
npm run dev
```

Acesse `http://localhost:5173`.

## Escopo desta etapa

- Dashboard responsivo do personal trainer;
- Carteira de alunos com busca e indicadores de adesão;
- Fichas de treino;
- Avaliações físicas;
- Agenda mensal;
- Modal de perfil e feedback visual;
- Componentes preparados para futura integração com a API FastAPI.

Os dados desta primeira versão são demonstrativos e ficam no frontend. A próxima etapa deve substituir os dados estáticos por autenticação, API e persistência no backend.
